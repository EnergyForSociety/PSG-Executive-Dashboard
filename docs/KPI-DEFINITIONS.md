# นิยาม KPI และ Mapping — PSG Executive Dashboard

หลักทั่วไป: เงินเป็นบาท (คำนวณเป็นสตางค์ด้วย Decimal) · เวลา Asia/Bangkok · ไม่มีข้อมูลแสดง N/A ไม่ใช่ 0 · ฐานศูนย์ไม่หารเปอร์เซ็นต์ · ไม่สร้างเป้าหมาย/เกณฑ์เอง

## ฐานเวลาที่แยกกัน

| ฐาน | แหล่ง | ใช้กับ |
|---|---|---|
| เดือนผลิต | ข้อความใน BL: "ประจำเดือน <เดือน> <ปี พ.ศ.>" หรือ "MM/YY" | kWh, ราคาเฉลี่ย, รายได้ตามรอบผลิต |
| วันที่ BL | B3 | ยอดเรียกเก็บ, ครบกำหนด, ค้างรับ |
| วันที่ IV/RV | IV3 (สถานะ Cash) | การรับชำระ (ใช้แทนวันเงินเข้าจนกว่าจะมี bank statement) |
| งวดบัญชี | Ledger (วันที่รายการ) | P&L ทุกบรรทัด |

Ledger ของรายได้ 4001000 บันทึกเป็น: ประมาณการสิ้นเดือน (เครดิต) → กลับรายการวันที่ 1 เดือนถัดไป (เดบิต) → รายได้จริงกลางเดือน (เครดิต) ดังนั้นรายได้งวดบัญชี M = ประมาณการ M + (จริง M−1 − ประมาณการ M−1) + รายการปรับปรุง (มีชุดทดสอบยืนยัน)

## ตารางความพร้อมของ KPI

| สถานะ | KPI |
|---|---|
| **ใช้ได้แล้ว** | รายได้/ต้นทุน/กำไรขั้นต้น/EBITDA/กำไรก่อนภาษีรายเดือน (ผลเบื้องต้น), ยอดเรียกเก็บ BL, ค้างรับ, อายุเจ้าหนี้, ความคลาดเคลื่อนประมาณการรายได้, ค่าซ่อมบำรุงตามบัญชี, ใบงานค้าง/อายุงาน/ใบงานตามเครื่อง/ข้อสังเกตคุณภาพ, รายการบันทึกสินทรัพย์ 1701xxx |
| **ต้องยืนยัน** | kWh ขายและราคาเฉลี่ย, ต้นทุนขายต่อ kWh, วันรับชำระ, หมวดต้นทุน 5101000 (รวม สลัดเค้ก = MIXCAKE?), การจัดกลุ่มบัญชี P&L, SLA ซ่อม |
| **รอแหล่งข้อมูล** | เงินสด/Cash Flow, kWh ผลิต/ใช้ภายใน/ส่งออก, ชั่วโมงเดิน/Availability, ต้นทุนวัตถุดิบต่อหน่วยและต่อ kWh, MTBF/MTTR/PM Compliance, ค่าซ่อมต่อใบงาน/เครื่องจักร, งบและความคืบหน้าโครงการ, เทียบปีก่อน |
| **ไม่เหมาะกับ PSG** | CRM (Lead/Opportunity/Win Rate/Sales Cycle/Pipeline/ลูกค้าใหม่), CLV, Resource Utilization |
