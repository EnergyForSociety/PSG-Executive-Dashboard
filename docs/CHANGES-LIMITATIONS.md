# สรุปการเปลี่ยนแปลงและข้อจำกัด — PSG Executive Dashboard (รุ่นแรก 15 พ.ย. 2569)

## สิ่งที่สร้าง
- โครงการใหม่ `PSG-Executive-Dashboard` จาก stack ของ SAM: adapter (TRCloud MCP ของ PSG แบบอ่านอย่างเดียว) → raw → normalization/mapping → calculation → UI → เข้ารหัส + Login M365
- 7 เมนู: Executive, การขาย, การเงิน, โครงการ, กลยุทธ์, ปฏิบัติการ (การผลิต / วัตถุดิบและต้นทุนผลิต / ซ่อมบำรุง), สถานะข้อมูล
- Management P&L จาก Ledger ทุกบัญชีที่มีรายการ (ดึงครบทุกหน้า), จัดกลุ่มตามหัวบัญชี COA ใน `config/mapping.json`
- ยอดขายฐาน BL + kWh จากข้อความ (เก็บข้อความต้นฉบับ กฎ สถานะยืนยัน) + การรับชำระจาก IV/RV แยกกัน
- ใบงานซ่อม 68 ใบ พร้อมข้อสังเกตคุณภาพข้อมูลและตารางเชื่อมใบงาน–PO ที่ต้องมีผู้ยืนยัน
- ธีม 3 แบบ (ปกติ = PSG Corporate, มืด, สว่าง) จำค่าที่เลือก · count-up ที่ยกเลิกชุดเก่าเมื่อเปลี่ยนตัวกรอง จบที่ค่าจริง อ่านค่าจริงด้วย aria-label · รองรับ reduced motion · กราฟมี tooltip (เมาส์และคีย์บอร์ด)
- เอกสาร README, นิยาม KPI/mapping/ความพร้อม, รายการขอข้อมูล, ผลทดสอบ, แม่แบบรับข้อมูล (`templates/`)

## ข้อจำกัดที่กระทบการตีความ
1. **ทุกเดือนเป็นผลเบื้องต้น** — ไม่มี API สถานะปิดบัญชี; งบทดลอง/งบดุล/กระแสเงินสดตอบ 402 (ต้องใช้แพ็กเกจ Data Warehouse)
2. **รายได้งวดล่าสุดเป็นประมาณการ** จนกว่าจะออก BL ของเดือนผลิตนั้น
3. **เงินสดไม่แสดง** — ยอดในทะเบียนธนาคารของ TRCloud เป็น 0 ทุกบัญชี จึงไม่ใช้
4. **kWh ขาย** อ่านจากข้อความ BL — ยังไม่ยืนยันกับมิเตอร์; ม.ค. 2569 และก่อนหน้าไม่มีหน่วยในข้อความ (N/A)
5. **ไม่มีข้อมูลผลิต** (generation, ชั่วโมงเดิน) จึงไม่มี Availability, MTBF, MTTR และต้นทุนต่อ kWh ผลิต
6. **ต้นทุนวัตถุดิบต่อหน่วย** ยังคำนวณไม่ได้ (ไม่มี Material Master และปริมาณรับ/ใช้)
7. **ค่าซ่อมบำรุงในบัญชีส่วนใหญ่เป็นประมาณการรายเดือน** — ผูกกับใบงาน/เครื่องจักรไม่ได้จนกว่าจะมีตารางเชื่อมที่ยืนยัน
8. **ใบงานเป็น snapshot** จากระบบแจ้งซ่อม — สถานะเครื่องหยุดในไฟล์ใช้สรุป downtime ไม่ได้
9. Ledger ที่ดึงเริ่ม ม.ค. 2569 จึงยังไม่มีการเทียบปีก่อน
10. CRM, CLV และ Resource Utilization ไม่แสดง เพราะไม่มีข้อมูลรองรับและไม่เหมาะกับธุรกิจลูกค้ารายเดียว

## ความปลอดภัย
- ใช้เฉพาะเครื่องมืออ่านของ TRCloud ของ PSG — adapter หยุดทันทีถ้าพบการเรียกเครื่องมือเขียนข้อมูล
- ข้อมูลจริงอยู่ใน `raw/ data/ om/` ซึ่งอยู่ใน `.gitignore` · เว็บมีเฉพาะ `data.enc.js` (AES-256-GCM) · build ตรวจไม่ให้เลขเอกสาร/ชื่อคู่ค้าหลุด
- ไม่มีความลับใน frontend (clientId/tenantId/groupId เปิดเผยได้) · กุญแจเก็บนอกโครงการและแชร์ผ่าน SharePoint เฉพาะกลุ่ม
- ไม่ได้เปลี่ยนคีย์ของบริษัทอื่น และไม่ได้แก้ประวัติ Git
